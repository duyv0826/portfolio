澳里·光景

Unity 6 · 系统设计与谜题管线 · 独立开发

  • 编写 204 个测试用例（EditMode + PlayMode + 确定性），覆盖状态机、经济、存档、可达性、配置完整性

工程能力

不是技能清单，是三个项目里反复出现、且能被代码证明的做法。

架构

  • 配置驱动：内容与逻辑分离，扩展走数据不走代码
  • 分层与依赖约束：asmdef 强制边界，Core 不反向依赖 Game
  • 事件总线：模块间通信解耦
  • 状态机：谜题与流程统一为可测状态模型

质量

  • 确定性模拟：同一输入序列可复现，结果可被自动验证
  • 回归断言：126 条已实跑全绿，204 条待 Unity 环境验证
  • 可达性校验：确保新增内容不会让玩家卡死
  • 配置完整性检查：数据错误在测试阶段暴露，不在运行时

工程习惯

  • 语法校验前置，逐节点校验后才推进下一步
  • 以断言锁定「扩展不破坏既有流程」
  • 素材溯源与许可证归档，AI 占位与成品分层管理
  • git 提交信息记录决策而非结果

工具与运维

  • Unity 6 / Godot 4.3 / JavaScript（UMD 双端）
  • Unity Test Framework（NUnit）、Godot 导出管线
  • 腾讯云 Lighthouse 自部署：new-api 中转、自建图床 imgbed
  • GitHub + SSH deploy key
