# ADR-002: 部署落腾讯云（Lighthouse 主推 / CloudBase 备选），否决 Vercel

## Status
Accepted (2026-10-09)

## Background
作品集面向国内受众，需大陆节点与可备案链路：

- Vercel 官方明确"在中国大陆没有服务器或 CDN 节点，无法保证大陆内的可用性与性能"；`*.vercel.app` 默认域名遭 GFW DNS 污染直接超时，自定义域名 CNAME 中继方案（enhanced-FaaS-in-China）每 40 分钟刷新 IP、三大运营商表现不一，仅适合玩具项目，**不满足作品集求职 / 校园大使的生产级可用性与 SEO**。
- 腾讯云 Lighthouse 新用户价 2 核 2G ≈ ¥68–99/年，单台跑 Docker Compose（Next.js + PostgreSQL + Caddy），全自管、国内节点、备案可达；MVP 年成本 ≈ 服务器 ¥100 + COS ¥10–50 + 域名 ¥50–80 ≈ ¥160–240（远低于 `development-costs` 隐性成本上限）。
- CloudBase 云托管备选：官方确认 Next.js 14/15/16 为一等公民，原生支持 SSR/SSG/ISR/API Routes/Middleware，镜像可落境内、域名可备案、与云数据库 / 对象存储内网互通。

## Decision
主推 **腾讯云轻量应用服务器 Lighthouse + Docker Compose** 部署；**CloudBase 云托管为备选**。明确否决 Vercel / Netlify 等海外方案（即便 DX 更优，也会直接破坏国内访问与百度 SEO）。

## Consequences
- 正面：合规可达（可 ICP 备案）；年成本低（¥160–240）；国内三网访问稳定；镜像落境内、域名可备案。
- 负面：DX 略低于 Vercel（需自管 Docker / 备份）；需自行处理 Caddy 自动 HTTPS 与每日 pg_dump 备份至 COS。
