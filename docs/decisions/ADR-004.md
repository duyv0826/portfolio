# ADR-004: 图标锁定 Lucide React（SVG），禁止 emoji

## Status
Accepted (2026-10-09)

## Background
团队 P0 硬规则（`architecture.md` §9 / §10）：仅 SVG 图标、禁 emoji 图标、禁硬编码颜色（唯一例外 `#fff` / `#000`）、禁紫→粉渐变、禁空洞占位文案。

需一套 tree-shakable、可主题化（`currentColor`）、内联 SVG 的图标方案，避免 emoji 跨平台渲染不一致、不可控配色与无障碍问题。

## Decision
图标库锁定 **Lucide React**（`lucide-react@^1.0`）：

- 仅此一家，禁止混用其他图标库，禁止任何 emoji 字符充当图标 / 装饰 / 状态指示。
- 颜色经 `currentColor` 由 Tailwind `@theme` 令牌 / CSS 变量（如 `var(--color-fg)`）控制，满足"禁硬编码颜色"。
- 图标名以官方为准（如 `Grid`→`LayoutGrid`、`Tool`→`Wrench` 等历史改名须核对），禁止凭记忆拼写（防幻觉依赖）。

## Consequences
- 正面：统一视觉语言；SVG 可主题化、tree-shakable，仅打包用到的图标；完全满足 P0 图标 / 配色约束。
- 负面：不可用 emoji 做快速占位 / 状态指示，须以 Lucide 图标 + 文字描述替代（如状态用文字 + `Check` / `Clock` 图标，不用 emoji 字符）。

## Related ADRs
- 关联 Designer 视觉规范（`architecture.md` §9 / §10）；无直接技术 ADR 依赖。
- 联动前端代码门禁：`grep` 全局确认无 emoji 作图标、仅 lucide-react import、无硬编码 hex（除 `#fff` / `#000`）、无紫粉渐变。
