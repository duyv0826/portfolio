# ADR-005: 数据库 PostgreSQL + Prisma 7 + COS 图床

## Status
Accepted (2026-10-09)

## Background
作品 / 博客 / 留言 / 订阅为强关联关系的内容站，需关系型存储与事务一致性；图片（作品图 / 头像 / 博客配图）需国内稳定、低成本的存储与 CDN。

- PostgreSQL 关系型契合内容站，`jsonb` 原生支持 `tags` / `gallery_urls` 数组，全文检索可用 `ILIKE`（MVP 数据量 < 1 万条，无需 MeiliSearch / ES，见 §12 out-of-scope）。
- 图床须国内稳定，且禁止把图片二进制写进 PostgreSQL（违反性能 / 容量纪律）。
- Prisma 7 默认走 `@prisma/adapter-pg` driver adapter，旧 `prisma@6` 直连写法不兼容，须按 7.x 文档实现。

## Decision
- 数据库：**PostgreSQL 16** + **Prisma 7**（schema-first + 迁移 + 类型安全），须使用 `@prisma/adapter-pg` + `pg` driver adapter。
- 对象存储：腾讯云 COS 标准存储 + CDN（`imgbed` 存储桶），图片 URL 存库；Bucket 私有 + CDN 回源鉴权，管理员上传走后端签名直传 / 中转。
- 软删除统一用 `deleted_at`；每表含 UUID 主键与 `created_at` / `updated_at`；外键显式。
- MVP 不建复合索引，查询慢再加（避免过早优化）。

## Consequences
- 正面：关系型数据一致；Prisma 迁移友好、类型安全；COS + CDN 国内稳定，成本可控；图片不占 PG 容量。
- 负面：需自管 PostgreSQL 备份（已规划每日 pg_dump → COS，保留 7 天）；Prisma 7 driver adapter 写法与 6.x 不兼容，须按 7.x 文档实现，否则运行时连接失败。
