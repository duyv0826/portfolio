# 真实图片投放清单

红线：**不使用 AI 生成原创图**（洪兄明确反对）。这里的坑位只接受两类来源——
① 你自己的作品截图 / 实拍；② 真实画师作品，**必须有授权 + 署名**。

在拿到图之前，页面走 AC-04 的中性占位（灰色块 + `data-artist` / `data-source` 空接口），不会崩、不会显示假图。

## 一、坑位与命名

图片统一放 `assets/`，文件名**照抄**（`projects.json` 已按此预留）：

| 文件名 | 用在哪 | 建议尺寸 | 优先级 |
|---|---|---|---|
| `hero-portrait.jpg` | 关于区（首屏旁）/ 个人形象 | 800×1000（4:5） | P1 |
| `cover-aoli-guangjing.jpg` | 《澳里·光景》封面 + 详情主图 | 1600×900（16:9） | **P0** |
| `cover-qingluan-tingyu.jpg` | 《青峦·听雨》封面 + 详情主图 | 1600×900 | **P0** |
| `cover-room-of-choice.jpg` | 《抉择的房间》封面 | 1600×900 | **P0** |
| `cover-tingyu-installation.jpg` | 《听雨 · 媒体装置》封面 | 1600×900 | P2 |

P0 这 3 张是首屏精选区直接露出的，缺了作品集的第一印象就是灰块。

## 二、格式要求

- 格式：`.jpg`（照片/渲染图）或 `.webp`（更小）；**不要**用图床外链（会失效，AC-11 红线）
- 体积：单张 ≤ 300KB，用 `sharp` / squoosh 压一遍
- 命名小写 + 连字符，不带中文、不带空格

## 三、填进 projects.json（每张图 3 个字段）

以《澳里·光景》为例，改这一段：

```json
{
  "img": "assets/cover-aoli-guangjing.jpg",
  "artist": "画师名 或 洪昺森",
  "source": "授权来源 / 授权方式（如：本人拍摄 / 画师授权 2026-09）"
}
```

- `img`：相对路径，**必须是 repo 相对或 https**（页面会拒掉其他协议）
- `artist`：署名；本人作品就写「洪昺森」
- `source`：来源说明；图库区会渲染成署名条（AC-12）

图库（`gallery.json`）每条同样有 `url` / `artist` / `source` 三字段。

## 四、放完之后

1. 本地起服务看一眼：`python -m http.server 8080 --bind 127.0.0.1`
2. 跑回归：`python verify/e2e.py`（15 项，含"无编造外链"守卫）
3. 确认每张图的 `artist` / `source` 都不是空字符串——空着等于没署名
